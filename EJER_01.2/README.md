# Curso práctico de TypeScript — 5 ejercicios

Cada carpeta `ejercicioN/` es independiente y trae su propio `README.md` con
los pasos exactos y los comandos a ejecutar en la terminal.

## Requisitos previos (una sola vez)

```bash
npm i -g typescript
npm -v
tsc -v
```

Si prefieres no instalar TypeScript globalmente, puedes usar `npx tsc`
en lugar de `tsc` en todos los comandos de este curso.

## Contenido

- **ejercicio1/** — Instalación y primer archivo `.ts` compilado.
- **ejercicio2/** — Tipos básicos, inferencia y objetos tipados.
- **ejercicio3/** — Interfaces, arrays y funciones tipadas.
- **ejercicio4/** — Uniones, tipos literales y enums.
- **ejercicio5/** — Mini proyecto con `src/`, `tsconfig.json` y `tsc -w`.

Sigue las carpetas en orden, del 1 al 5.
