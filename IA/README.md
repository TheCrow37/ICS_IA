# Registro de notas · proyecto completado

Aplicación React + TypeScript para registrar notas de módulos, consultar la media y ver cuántos están aprobados.

```bash
npm install
npm run dev      # servidor de desarrollo
npm run build    # comprueba los tipos y genera la compilación
```

La clasificación utilizada es: suspenso (< 5), aprobado (5–< 7), notable (7–< 9) y sobresaliente (9–10). El ZIP de partida hacía referencia al enunciado del examen, pero no lo incluía; se han completado los apartados señalados por los comentarios `APARTADO 1–5` y los requisitos visibles en el propio código.
